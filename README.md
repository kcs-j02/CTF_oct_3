# CTF参加記録・学習ノート

現地開催のCTFに参加し、**200名中99位**となりました。
エンコーディング、ファイル解析、ネットワーク解析、Web通信などの課題に取り組みました。

## 学んだこと

- 数値列や文字列の形式を見極め、適切な方法でデコードすること。
- 文字化けについて、文字コードの取り違えを仮説として検証すること。
- 画像の表示結果だけでなく、ヘッダや内部構造を調べること。
- 通信ログからプロトコルを特定し、転送されたファイルも調査すること。
- HTTPのヘッダ、Cookie、CSRFトークンなどの役割を理解すること。
- Linuxコマンドで手掛かりを集め、仮説・検証・記録を繰り返すこと。
- 暗号解析する際にすごい役に立ったサイトhttps://dencode.com/ja/cipher
